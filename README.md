# Ecommerce demo

Aplicación básica de ecommerce con Node.js y Express. Permite:

- Crear categorías.
- Subir productos asociados a una categoría.
- Listar productos por categoría.
- Ver precios en dólares y su conversión a córdobas.

## Ejecutar

```bash
npm install
npm start
```

La aplicación se ejecuta en `http://localhost:3000`.

## Pruebas

```bash
npm test
```
